Orçamento de hospedagem e domínio

Comparativo inicial para decidir como publicar o site. Preços e condições mudam; confira os sites oficiais antes de entregar o orçamento definitivo.

Comparativo de domínio

OpçãoO que pesquisarObservação

Justificativa

Para esta entrega, o Railway é o destino indicado no roteiro da disciplina. Um endereço .up.railway.app permite testar sem comprar domínio. Para um orçamento acadêmico completo, a equipe deve registrar a data da consulta, o preço mensal e anual, limites, HTTPS, integração GitHub e evidências dos sites oficiais.

Fontes para consulta: Railway Pricing, GitHub Pages, Netlify Pricing, Registro.br e Cloudflare Registrar.
